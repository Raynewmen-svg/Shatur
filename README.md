## 🔧 Setup Instructions

### 1. Install Theme
1. Download the theme ZIP from GitHub
2. Go to WordPress Admin → Appearance → Themes
3. Click "Add New" → "Upload Theme"
4. Select the ZIP file and upload
5. Click "Activate"

### 2. Create Pages
WordPress will auto-detect the templates. Create pages:
- Home (use "Front Page" template if needed)
- Franshiza (use "Franchise" template)
- Kontakty (use "Contacts" template)

### 3. Install Contact Form 7
1. Go to Plugins → Add New
2. Search for "Contact Form 7"
3. Install and Activate
4. Create a new form or use the default
5. Copy the shortcode: `[contact-form-7 id="1" title="Contact Form"]`

### 4. Add Contact Form to Contacts Page
1. Edit the Contacts page
2. Find the form section
3. Replace the placeholder with the Contact Form 7 shortcode
4. Save

## 🎨 Customization

### Colors
Edit `style.css` CSS variables:
```css
--wp--preset--color--dark-green: #295b2d;
--wp--preset--color--light-green: #7bc242;
--wp--preset--color--brand-red: #d52828;
```

### Typography
Edit font families in `style.css`

### Add Gallery
1. Go to Home page editor
2. Add gallery block
3. Upload strawberry images
4. Arrange as needed
