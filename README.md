# Shatur Theme

Полноценная FSE-тема WordPress для фермы Шатурская клубника.

## Особенности

- ✅ Full Site Editing (FSE)
- ✅ Hero с фоном
- ✅ Contact Form 7 интеграция
- ✅ Отзывчивый дизайн
- ✅ Цветовая палитра

## Ос и требования

- WordPress 6.0+
- PHP 7.4+

## Установка

1. Нагружаюте всю папку в `wp-content/themes/shatur-theme/`
2. Активируюте тему в WordPress Admin
