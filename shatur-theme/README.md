# Shatur Theme – WordPress Full Site Editing

## Installation

1. Download and extract this theme to `wp-content/themes/shatur-theme/`
2. Go to WordPress Admin → Appearance → Themes
3. Find "Shatur Theme" and click Activate
4. Install and activate "Contact Form 7" plugin (if not already installed)

## Demo Content Import

1. WordPress Admin → Tools → Import → WordPress
2. Upload `demo-content.xml`
3. Assign posts to admin user

## Contact Form 7 Setup

1. WordPress Admin → Contact → Contact Forms
2. Create new form or edit existing
3. Set email notification to: **raynewme@yandex.ru**

## Customization

- Hero image: Replace `assets/hero-poster.svg` with your own image
- Gallery images: Add images to `assets/` folder
- Logo: Replace `assets/favicon.svg` with your logo
- Colors: Edit `theme.json` to change color palette
- Text: Use WordPress Editor (Site Editor) to modify content

## Recommended Plugins

- Contact Form 7
- Yoast SEO
- WP Fastest Cache
